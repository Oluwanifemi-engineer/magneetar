# Privacy Policy

**Effective Date**: September 3, 2026  
**Last Updated**: September 3, 2026

## Overview

Magneetar ("we", "our", or "us") provides anti-theft tracking and device recovery services. This Privacy Policy explains how we collect, use, store, and protect your personal information when you use the Magneetar mobile app and web dashboard.

---

## Information We Collect

### 1. Device Information
- **Device Identifiers**: Android device ID, model, manufacturer
- **Operating System**: Android version
- **App Version**: Magneetar app version

### 2. Location Data
- **GPS Coordinates**: Latitude, longitude, accuracy, speed, bearing
- **Location History**: Timestamped location points for tracking purposes
- **Background Location**: We collect location data even when the app is closed or not in use for anti-theft protection

### 3. Device Telemetry
- **Battery Status**: Battery level and charging state
- **Network Information**: Network type (WiFi, 4G, 3G, etc.)
- **SIM Card Information**: Hashed SIM serial number (for SIM change detection)
- **Device Admin Status**: Whether device administrator privileges are active

### 4. Evidence Media
- **Photos**: Front-camera captures triggered by theft detection or user command
- **Audio Recordings**: 10-second audio clips triggered by theft detection or user command
- **Timestamps and Locations**: Associated with each piece of evidence

### 5. Account Information
- **Email Address**: Used for account creation and authentication
- **Password**: Securely hashed using bcrypt
- **Display Name**: Optional user-provided name

### 6. Usage Data
- **API Requests**: Endpoint access logs, timestamps
- **Commands Issued**: Device commands (lock, alarm, capture, etc.)
- **WebSocket Connections**: Real-time update subscriptions

---

## How We Use Your Information

### Primary Uses
- **Anti-Theft Protection**: Monitor device location and status to help recover stolen devices
- **Evidence Collection**: Capture photos and audio when theft is suspected
- **Geofencing**: Alert you when devices enter or leave defined areas
- **Device Management**: Enable remote lock, alarm, and wipe commands
- **Family Safety**: Help families track each other's devices with consent

### Secondary Uses
- **Service Improvement**: Analyze usage patterns to improve features
- **Security**: Detect and prevent unauthorized access and abuse
- **Support**: Respond to user inquiries and troubleshoot issues
- **Legal Compliance**: Comply with legal obligations and law enforcement requests

---

## Background Location Collection

**Magneetar collects location data to enable anti-theft tracking even when the app is closed or not in use.**

- Location is collected every 3-5 minutes when tracking is active
- Location history is stored for up to 90 days (configurable)
- You can disable tracking at any time in the app settings
- Background location is essential for recovering stolen devices

## Data Security

We implement industry-standard security measures:

- **Encryption in Transit**: All API traffic uses TLS 1.3
- **Encryption at Rest**: Sensitive data (passwords, API keys) encrypted with AES-256
- **Access Controls**: Role-based permissions and multi-factor authentication
- **Regular Audits**: Security reviews and penetration testing
- **Data Minimization**: We collect only what's necessary for service functionality
